# Name generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `rl-rules::namegen`, a seeded name generator read from RON, which Undermere's townsfolk (part 5) and mercenaries (part 6) are named by.

**Architecture:** One tier 1 module. A file is a map of named sets; a set is named syllable pools, weighted patterns of parts, a case, a length and forbidden substrings. Load resolves every pool a pattern names to an index and checks the shape; a draw assembles one name by a pattern drawn by weight, applies the case, and redraws a bounded number of times while the rejections refuse it.

**Tech Stack:** Rust, `rand` 0.9 (`random_range`), `serde`, `ron` 0.10.

**Spec:** `docs/superpowers/specs/2026-10-08-undermere-mercenaries-design.md`, "Engine work", slice 1 "Names", on branch `undermere`. Built on branch `namegen` from `main`, ahead of parts 3 to 6, since part 5 needs it first.

## Global Constraints

- Tier 1: no Bevy, builds on `wasm32-unknown-unknown`, no `std::time::Instant`.
- No `HashMap`/`HashSet`: `BTreeMap` for sets and pools, so load order and iteration never depend on hashing.
- Randomness only from the caller's `&mut impl Rng`; the engine never makes a generator, so load cannot sample a set.
- `#![deny(missing_docs)]`; doc-tests run, never `ignore`.
- No theme words in the engine: tests and docs use neutral syllables.
- The RON schema's option space is written in the module docs, for a game's file to copy into its top-of-file comment.
- Plain dash, never an em dash.

## Review Focus

- A set whose rejections refuse nearly everything: `draw` must return `None` after `ATTEMPTS`, never loop. Test: a set that can only make `"aaa"` returns `None`.
- `draw_distinct` with every possible name taken returns `None`. Test: a one-name set with that name taken.
- A pool named by a pattern but missing, or a pool no pattern names: load fails naming the set and the pool. Tests for both.
- Non-ASCII syllables (`"ø"`, `"é"`): length counts characters, not bytes, and case maps by `char`. Test: `Title` on `"ørn"` gives `"Ørn"`, and a `length: (3, 3)` set accepts it.
- The same stream draws the same name: a property over a range of seeds comparing two generators from one seed.

**Interfaces (produced, for parts 5 and 6):**
- `pub fn load(text: &str) -> Result<NameBook, ContentError>`
- `pub struct NameBook`; `NameBook::set(&self, name: &str) -> Option<&NameSet>`; `NameBook::sets(&self) -> impl Iterator<Item = (&str, &NameSet)>`
- `pub struct NameSet`; `draw(&self, rng: &mut impl Rng) -> Option<String>`; `draw_distinct(&self, rng: &mut impl Rng, taken: impl Fn(&str) -> bool) -> Option<String>`; `accepts(&self, name: &str) -> bool`
- `pub enum Case { Title, Upper, Lower, AsWritten }`, `Title` by default
- `pub const ATTEMPTS: u32 = 100`

**The file, as a game writes it:**

```ron
{
    "person": (
        pools: {
            "start": ["ka", "lo", "mer"],
            "middle": ["a", "en"],
            "end": ["n", "dra", "vik"],
            "byname": ["the Elder"],
        },
        patterns: [
            (weight: 3, parts: [Pool("start"), Maybe(35, "middle"), Pool("end")]),
            (weight: 1, parts: [Pool("start"), Pool("end"), Text(" "), Pool("byname")]),
        ],
        case: Title,
        length: (3, 20),
        forbid: ["kak"],
    ),
}
```

`case`, `length` and `forbid` may be left out: `Title`, `(1, 32)` and none.
`Pool(p)` is one syllable of `p`; `Maybe(pct, p)` is one `pct` times in a hundred; `Text(t)` is `t` as written.

**Load refuses, every failure listed in one `ContentError::Invalid`, each prefixed `set "<name>":`:**
a set with no patterns; a pattern with weight nought or no parts; a `Pool`/`Maybe` naming a missing pool; a pool that is empty or holds an empty syllable; a pool no pattern names; a `Maybe` chance of nought or over a hundred; `length` with a nought minimum or minimum above maximum; a pattern whose shortest and longest possible names (in characters, a `Maybe` counted as absent and as its longest) miss the length bounds entirely.

**A drawn name is refused** (compared lowercased, after the case is applied) when it:
is outside `length` in characters; starts or ends with a space or holds two together; holds one character three times running; holds a pair repeated back to back (`abab`); holds a run of three non-space characters again later; holds a `forbid` substring.

**Case:** `Title` uppercases the first character of each word, after a space or a hyphen, and lowercases the rest; `Upper` and `Lower` the whole; `AsWritten` nothing.

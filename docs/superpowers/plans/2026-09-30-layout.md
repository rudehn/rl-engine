## Review Focus

1. A map too small for any shape of the recipe (for example 10 by 10 with a 7-cell room): `Accrete` returns a `BuildError` naming the problem, and never panics or loops forever.
2. An `Accrete` built in code with no shapes, no districts or an all-zero weight list: a `BuildError`, never a panic from `random_range(0..0)`.
3. A target open share that cannot be reached: growth stops after `patience` failed attempts in a row and fails, and never hangs.
4. Two openings side by side: `OpenLoops` never opens a cell orthogonally beside an existing opening, so no two-wide accidental gap appears in a wall.
5. A start that cannot walk to the exit (a stamp walled one off): `Survey` returns a `BuildError`, never panics on an unreached distance.

Each has a test in the task that owns the code: 1, 2 and 3 in Task 3, 4 in Task 4, 5 in Task 5.

Replace `Chain::run` with:

```rust
    /// Runs every pass over `ctx`.
    ///
    /// Each pass is handed a stream derived from `seed` and its own name, so
    /// adding, removing or reordering a pass cannot change what any other
    /// pass draws. Stops at the first failure and reports it.
    pub fn run(&self, ctx: &mut C, seed: RunSeed) -> Result<(), BuildError> {
        self.run_attempt(ctx, seed, 0)
    }

    /// One attempt: every pass's stream is derived at `attempt`, so two
    /// attempts of one seed draw nothing in common and attempt nought is
    /// what [`run`](Self::run) builds.
    fn run_attempt(&self, ctx: &mut C, seed: RunSeed, attempt: u32) -> Result<(), BuildError> {
        for pass in &self.passes {
            ctx.set_rng(seed.rng(SeedDomain::new(pass.name().as_bytes()), u64::from(attempt)));
            pass.apply(ctx)?;
            ctx.take_snapshot();
        }
        Ok(())
    }

    /// Runs the chain over a fresh context from `make`, again from the
    /// next attempt each time a pass fails, and hands back the first
    /// context that every pass finished, or the last failure once
    /// `attempts` are spent.
    ///
    /// A generator loose enough to surprise is only safe when what it gets
    /// wrong is thrown away. A failed pass may have written half its work,
    /// so each attempt starts from a context nothing has touched. The
    /// attempt is an index into each pass's stream and nothing else, so one
    /// seed builds one place however many attempts that took.
    ///
    /// # Panics
    /// Panics if `attempts` is nought: a chain that may not run has no
    /// place and no error to hand back.
    pub fn run_retrying(&self, make: impl Fn() -> C, seed: RunSeed, attempts: u32) -> Result<C, BuildError> {
        assert!(attempts > 0, "a chain needs at least one attempt");
        let mut last = None;
        for attempt in 0..attempts {
            let mut ctx = make();
            match self.run_attempt(&mut ctx, seed, attempt) {
                Ok(()) => return Ok(ctx),
                Err(e) => last = Some(e),
            }
        }
        Err(last.expect("at least one attempt ran"))
    }
```

```rust
//! Growing a place piece by piece.
//!
//! A [`Shape`] draws a [`Piece`]: the floor of one area and the [sites
//! ](Piece::sites) where it may be joined to another. [`Accrete`] lays a
//! first piece and attaches every later one to a wall of what already
//! stands, so the place is walkable from end to end before anything checks
//! that it is.

use rand::{Rng, RngCore};
use rl_core::{Direction, Point, Rect};

/// How a piece is joined to the one it is attached to.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Join {
    /// One cell of the door tile.
    Door,
    /// One cell of floor: a way through with nothing to open.
    Arch,
    /// Floor as wide as both pieces allow, up to this many cells, so a
    /// large piece opens onto its neighbour rather than hiding behind a
    /// doorway.
    Mouth(u8),
}

/// The floor of one area, relative to its own corner, and where it may be
/// joined.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Piece {
    /// The body: every cell of floor, none negative, sorted by row then
    /// column.
    pub cells: Vec<Point>,
    /// Each cell outside the body that touches exactly one body cell
    /// orthogonally, with the direction that leads out of the body through
    /// it. A cell touching two is in a concave corner, and a door there
    /// would open onto the piece's own wall.
    pub sites: Vec<(Point, Direction)>,
}

impl Piece {
    /// The piece whose body is `cells`, with every site worked out.
    pub fn from_cells(mut cells: Vec<Point>) -> Self {
        cells.sort_by_key(|p| (p.y, p.x));
        cells.dedup();
        let has = |p: Point| cells.binary_search_by_key(&(p.y, p.x), |c| (c.y, c.x)).is_ok();
        let mut sites = Vec::new();
        for &c in &cells {
            for d in Direction::CARDINALS {
                let p = c + d.offset();
                if !has(p) && Direction::CARDINALS.iter().filter(|n| has(p + n.offset())).count() == 1 {
                    sites.push((p, d));
                }
            }
        }
        Self { cells, sites }
    }

    /// Whether the piece has no floor at all.
    pub fn is_empty_piece(&self) -> bool {
        self.cells.is_empty()
    }
}

/// The smallest rectangle holding every one of `cells`; empty for none.
pub(crate) fn bounds_of(cells: &[Point]) -> Rect {
    let Some(first) = cells.first() else {
        return Rect::new(0, 0, 0, 0);
    };
    let (mut x0, mut y0, mut x1, mut y1) = (first.x, first.y, first.x, first.y);
    for c in cells {
        x0 = x0.min(c.x);
        y0 = y0.min(c.y);
        x1 = x1.max(c.x);
        y1 = y1.max(c.y);
    }
    Rect::new(x0, y0, x1 - x0 + 1, y1 - y0 + 1)
}

/// The largest rectangle made only of `cells`, which all lie in `bounds`.
/// It is where a stamp is centred, so an area that is not a rectangle
/// still has one to offer.
pub(crate) fn largest_rect(cells: &[Point], bounds: Rect) -> Rect {
    let (w, h) = (bounds.width as usize, bounds.height as usize);
    let mut filled = vec![false; w * h];
    for c in cells {
        filled[(c.y - bounds.y) as usize * w + (c.x - bounds.x) as usize] = true;
    }
    let mut best = Rect::new(bounds.x, bounds.y, 0, 0);
    for top in 0..h {
        // Whether column x is floor on every row from `top` to `y`.
        let mut column = vec![true; w];
        for y in top..h {
            for x in 0..w {
                column[x] &= filled[y * w + x];
            }
            let mut x = 0;
            while x < w {
                if !column[x] {
                    x += 1;
                    continue;
                }
                let start = x;
                while x < w && column[x] {
                    x += 1;
                }
                let r = Rect::new(bounds.x + start as i32, bounds.y + top as i32, (x - start) as i32, (y - top + 1) as i32);
                if r.area() > best.area() {
                    best = r;
                }
            }
        }
    }
    best
}

/// Draws one piece. A trait and not a list, so a game draws a piece the
/// engine never thought of.
pub trait Shape: Send + Sync {
    /// The shape's name, which an [`Area`] it drew carries. The engine
    /// reads no meaning into it.
    fn name(&self) -> &str;

    /// How a piece of this shape is joined to what it is attached to.
    fn join(&self) -> Join;

    /// Whether a piece of this shape is somewhere a prefab may be stamped.
    /// A passage is not: it emits no `Room`, so nothing furnishes it.
    fn is_room(&self) -> bool {
        true
    }

    /// One piece, from the pass's own stream.
    fn draw(&self, rng: &mut dyn RngCore) -> Piece;
}

/// A rectangle, each side drawn between a smallest and a largest.
#[derive(Debug, Clone)]
pub struct Rectangle {
    /// The shape's name.
    pub name: String,
    /// The width, smallest and largest, in cells of floor.
    pub w: (i32, i32),
    /// The height, smallest and largest.
    pub h: (i32, i32),
    /// How it is joined.
    pub join: Join,
}

impl Shape for Rectangle {
    fn name(&self) -> &str {
        &self.name
    }
    fn join(&self) -> Join {
        self.join
    }
    fn draw(&self, rng: &mut dyn RngCore) -> Piece {
        let w = rng.random_range(self.w.0..=self.w.1);
        let h = rng.random_range(self.h.0..=self.h.1);
        Piece::from_cells(Rect::new(0, 0, w, h).cells().collect())
    }
}

/// Two bars overlapped on their centers, each `long` by `short`, one lying
/// and one standing.
#[derive(Debug, Clone)]
pub struct Cross {
    /// The shape's name.
    pub name: String,
    /// A bar's length, smallest and largest.
    pub long: (i32, i32),
    /// A bar's thickness, smallest and largest; less than the length, or
    /// the cross is a rectangle.
    pub short: (i32, i32),
    /// How it is joined.
    pub join: Join,
}

impl Shape for Cross {
    fn name(&self) -> &str {
        &self.name
    }
    fn join(&self) -> Join {
        self.join
    }
    fn draw(&self, rng: &mut dyn RngCore) -> Piece {
        let (lying, standing) = (rng.random_range(self.long.0..=self.long.1), rng.random_range(self.long.0..=self.long.1));
        let (thick_l, thick_s) = (rng.random_range(self.short.0..=self.short.1), rng.random_range(self.short.0..=self.short.1));
        let mut cells: Vec<Point> = Rect::new(0, (standing - thick_l) / 2, lying, thick_l).cells().collect();
        cells.extend(Rect::new((lying - thick_s) / 2, 0, thick_s, standing).cells());
        Piece::from_cells(cells)
    }
}

/// A run of floor a few cells wide, straight or with one bend.
#[derive(Debug, Clone)]
pub struct Passage {
    /// The shape's name.
    pub name: String,
    /// The width, smallest and largest.
    pub width: (i32, i32),
    /// The length of each leg, smallest and largest.
    pub length: (i32, i32),
    /// The chance in a hundred of a second leg at a right angle.
    pub bend_pct: u32,
    /// How it is joined.
    pub join: Join,
}

impl Shape for Passage {
    fn name(&self) -> &str {
        &self.name
    }
    fn join(&self) -> Join {
        self.join
    }
    fn is_room(&self) -> bool {
        false
    }
    fn draw(&self, rng: &mut dyn RngCore) -> Piece {
        let width = rng.random_range(self.width.0..=self.width.1);
        let first = rng.random_range(self.length.0..=self.length.1).max(width);
        let mut cells: Vec<Point> = Rect::new(0, 0, first, width).cells().collect();
        if rng.random_range(0..100) < self.bend_pct {
            let second = rng.random_range(self.length.0..=self.length.1).max(width);
            cells.extend(Rect::new(first - width, 0, width, second).cells());
        }
        // Lying or standing, so a passage runs either way off a wall.
        if rng.random_bool(0.5) {
            for c in &mut cells {
                *c = Point::new(c.y, c.x);
            }
        }
        Piece::from_cells(cells)
    }
}
```

```rust
/// A region's taste in shapes: a name and the shapes drawn there, by
/// weight. It biases a draw and builds nothing, so no wall follows a
/// district's edge and a recipe with one district is the pass with none.
#[derive(Debug, Clone)]
pub struct District {
    /// The district's name, which an [`Area`] grown in it carries.
    pub name: String,
    /// Each an index into [`Accrete::shapes`] and the weight it is drawn at.
    pub shapes: Vec<(usize, u32)>,
}

/// One piece as it was laid: what a later pass needs to decide what
/// belongs in it.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Area {
    /// Its place in the order the pieces were laid; an [`Opening`] names
    /// its two areas by this.
    pub index: usize,
    /// The name of the shape that drew it.
    pub shape: String,
    /// The name of the district it was grown in.
    pub district: String,
    /// Every cell of its floor, in map coordinates.
    pub cells: Vec<Point>,
    /// The smallest rectangle holding them.
    pub bounds: Rect,
    /// The largest rectangle made only of them: where a stamp is centred.
    pub inner: Rect,
}

/// A way between two areas.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Opening {
    /// The cells opened in the wall between them; the first is where the
    /// two were joined, and a mouth has more.
    pub cells: Vec<Point>,
    /// The direction that leads from the first area to the second.
    pub facing: Direction,
    /// The two areas, by [`Area::index`].
    pub areas: (usize, usize),
    /// How they were joined.
    pub join: Join,
}

/// Grows a place by accretion over a map of solid tile: a first piece,
/// then each later one attached to a wall of what already stands.
///
/// Every area is joined to one that was already joined, so every open cell
/// can be walked to from every other by construction. A piece fits only
/// where its body and the ring one cell round it are solid, which leaves
/// exactly one wall between two areas and never none.
///
/// Every number is a share or a density, never a count of cells of map, so
/// one recipe grows a small place and a large one. It fails if the open
/// share is not reached before `patience` attempts in a row are spent.
pub struct Accrete {
    /// The tile a piece's body is carved from.
    pub floor: TileId,
    /// The tile a [`Join::Door`] opens as.
    pub door: TileId,
    /// Every shape a district may draw.
    pub shapes: Vec<Box<dyn Shape>>,
    /// Every district the mix may scatter.
    pub districts: Vec<District>,
    /// Each an index into `districts` and the weight a seed draws it at.
    pub mix: Vec<(usize, u32)>,
    /// District seeds per ten thousand cells of map, rounded, at least one.
    pub districts_per_10k: u32,
    /// The share of the map, in a hundred, to open before stopping.
    pub open_pct: u32,
    /// How many attempts in a row may fail before growth gives up.
    pub patience: u32,
}

fn solid(terrain: &Terrain, walkable: &[bool], p: Point) -> bool {
    terrain.get(p).is_some_and(|t| !walkable[t.index()])
}

/// Whether a piece moved by `by` lies inside `inner` with its body and the
/// ring round it all solid.
fn fits(terrain: &Terrain, walkable: &[bool], inner: Rect, cells: &[Point], by: Point) -> bool {
    cells.iter().all(|c| {
        let p = *c + by;
        inner.contains(p) && (-1..=1).all(|dy| (-1..=1).all(|dx| solid(terrain, walkable, p.offset(dx, dy))))
    })
}

fn draw_weighted(rows: &[(usize, u32)], rng: &mut dyn RngCore) -> Option<usize> {
    let weights: Vec<u32> = rows.iter().map(|(_, w)| *w).collect();
    let total = weights.iter().try_fold(0u32, |sum, w| sum.checked_add(*w)).filter(|t| *t > 0)?;
    Some(rows[pick_weighted(&weights, rng.random_range(0..total))].0)
}

impl Accrete {
    fn err(reason: impl Into<String>) -> BuildError {
        BuildError::new("accrete", reason)
    }

    /// What can be told is wrong before a cell is drawn, so a mistake in
    /// how the pass was built is one error and not a panic mid-growth.
    fn check(&self) -> Result<(), BuildError> {
        if self.shapes.is_empty() || self.districts.is_empty() {
            return Err(Self::err("it has no shapes or no districts to draw from"));
        }
        let weighs = |rows: &[(usize, u32)], len: usize| rows.iter().all(|(i, _)| *i < len) && rows.iter().any(|(_, w)| *w > 0);
        if !weighs(&self.mix, self.districts.len()) {
            return Err(Self::err("its mix names no district with a weight"));
        }
        for d in &self.districts {
            if !weighs(&d.shapes, self.shapes.len()) {
                return Err(Self::err(format!("district {:?} names no shape with a weight", d.name)));
            }
        }
        Ok(())
    }
}

impl<C: BuildContext> Pass<C> for Accrete {
    fn name(&self) -> &'static str {
        "accrete"
    }
    fn phase(&self) -> Phase {
        Phase::Structures
    }
    fn apply(&self, ctx: &mut C) -> Result<(), BuildError> {
        self.check()?;
        let walkable = ctx.tiles().tables().walkable.clone();
        let bounds = ctx.terrain().bounds();
        let inner = bounds.inflate(-1);
        if inner.width < 1 || inner.height < 1 {
            return Err(Self::err("the map has no room inside its border"));
        }
        let total = (bounds.width * bounds.height) as u32;

        let seed_count = ((total * self.districts_per_10k + 5_000) / 10_000).max(1);
        let mut seeds = Vec::new();
        for _ in 0..seed_count {
            let at = Point::new(ctx.rng().random_range(inner.x..inner.right()), ctx.rng().random_range(inner.y..inner.bottom()));
            seeds.push((at, draw_weighted(&self.mix, ctx.rng()).expect("checked")));
        }
        // `min_by_key` keeps the first of equals, so a tie goes to the earlier seed.
        let district_at = |p: Point| seeds.iter().min_by_key(|(s, _)| euclidean_sq(*s, p)).expect("at least one seed").1;

        let mut owner = Grid::<u32>::filled(bounds.width, bounds.height, 0);
        let mut areas: Vec<Area> = Vec::new();
        let mut openings: Vec<Opening> = Vec::new();
        let mut frontier: Vec<(Point, Direction, usize)> = Vec::new();
        let mut open = 0u32;

        // Lays `piece` moved by `by`, and returns its index.
        let mut lay = |ctx: &mut C, piece: &Piece, by: Point, shape: usize, district: usize, used: Option<Point>, areas: &mut Vec<Area>, frontier: &mut Vec<(Point, Direction, usize)>, owner: &mut Grid<u32>| {
            let index = areas.len();
            let cells: Vec<Point> = piece.cells.iter().map(|c| *c + by).collect();
            for c in &cells {
                ctx.terrain_mut().set(*c, self.floor);
                owner.set(*c, index as u32 + 1);
            }
            frontier.extend(piece.sites.iter().map(|(q, d)| (*q + by, *d, index)).filter(|(q, _, _)| Some(*q) != used));
            let b = bounds_of(&cells);
            areas.push(Area { index, shape: self.shapes[shape].name().to_string(), district: self.districts[district].name.clone(), inner: largest_rect(&cells, b), bounds: b, cells });
            index
        };

        // The first piece, anywhere it fits.
        let mut laid = false;
        for _ in 0..self.patience {
            let at = Point::new(ctx.rng().random_range(inner.x..inner.right()), ctx.rng().random_range(inner.y..inner.bottom()));
            let district = district_at(at);
            let shape = draw_weighted(&self.districts[district].shapes, ctx.rng()).expect("checked");
            let piece = self.shapes[shape].draw(ctx.rng());
            if fits(ctx.terrain(), &walkable, inner, &piece.cells, at) {
                open += piece.cells.len() as u32;
                lay(ctx, &piece, at, shape, district, None, &mut areas, &mut frontier, &mut owner);
                laid = true;
                break;
            }
        }
        if !laid {
            return Err(Self::err(format!("no first piece fit a {}x{} map in {} attempts", bounds.width, bounds.height, self.patience)));
        }

        let mut spent = 0;
        while open * 100 < self.open_pct * total && spent < self.patience && !frontier.is_empty() {
            let i = ctx.rng().random_range(0..frontier.len());
            let (site, facing, from) = frontier[i];
            let beyond = site + facing.offset();
            // A site another piece has since grown over or against leads nowhere.
            if !solid(ctx.terrain(), &walkable, site) || !inner.contains(beyond) || !solid(ctx.terrain(), &walkable, beyond) {
                frontier.swap_remove(i);
                continue;
            }
            let district = district_at(site);
            let shape = draw_weighted(&self.districts[district].shapes, ctx.rng()).expect("checked");
            let piece = self.shapes[shape].draw(ctx.rng());
            let mut meets: Vec<Point> = piece.sites.iter().filter(|(_, d)| *d == facing.opposite()).map(|(q, _)| *q).collect();
            meets.shuffle(ctx.rng());
            let Some(by) = meets.iter().map(|q| site - *q).find(|by| fits(ctx.terrain(), &walkable, inner, &piece.cells, *by)) else {
                spent += 1;
                continue;
            };
            spent = 0;
            frontier.swap_remove(i);
            open += piece.cells.len() as u32;
            let to = lay(ctx, &piece, by, shape, district, Some(site), &mut areas, &mut frontier, &mut owner);

            let join = self.shapes[shape].join();
            let mut cells = vec![site];
            ctx.terrain_mut().set(site, if join == Join::Door { self.door } else { self.floor });
            if let Join::Mouth(width) = join {
                // Widen along the wall while the same two areas face each other across it.
                for side in facing.perpendicular() {
                    let mut q = site + side.offset();
                    while cells.len() < width as usize
                        && solid(ctx.terrain(), &walkable, q)
                        && owner.get(q - facing.offset()).copied() == Some(from as u32 + 1)
                        && owner.get(q + facing.offset()).copied() == Some(to as u32 + 1)
                    {
                        ctx.terrain_mut().set(q, self.floor);
                        cells.push(q);
                        q = q + side.offset();
                    }
                }
            }
            open += cells.len() as u32;
            openings.push(Opening { cells, facing, areas: (from, to), join });
        }

        if open * 100 < self.open_pct * total {
            return Err(Self::err(format!("grew to {}% open of the {}% asked for", open * 100 / total, self.open_pct)));
        }
        for area in areas {
            let is_room = self.shapes.iter().find(|s| s.name() == area.shape).is_some_and(|s| s.is_room());
            if is_room {
                ctx.emit(Room(area.inner));
            }
            ctx.emit(area);
        }
        for opening in openings {
            ctx.emit(opening);
        }
        Ok(())
    }
}
```

```rust
//! Counting steps over open cells, for the passes that ask how far one
//! place is from another on foot.
//!
//! Orthogonal steps and no costs: the strictest reading of "can be walked
//! to", and a generator comparing two routes wants their lengths, not how
//! long a particular mover takes over them.

use std::collections::VecDeque;

use rl_core::{Direction, Grid, Point};

/// The count at a cell no source reaches.
pub(crate) const UNREACHED: u32 = u32::MAX;

/// Orthogonal steps to every open cell from the nearest of `from`.
pub(crate) fn steps_from(width: i32, height: i32, open: impl Fn(Point) -> bool, from: impl IntoIterator<Item = Point>) -> Grid<u32> {
    let mut steps = Grid::filled(width, height, UNREACHED);
    let mut queue = VecDeque::new();
    for p in from {
        if open(p) && steps.get(p).copied() == Some(UNREACHED) {
            steps.set(p, 0);
            queue.push_back(p);
        }
    }
    while let Some(p) = queue.pop_front() {
        let next = steps.get(p).copied().expect("queued cells are on the grid") + 1;
        for d in Direction::CARDINALS {
            let n = p + d.offset();
            if steps.get(n).copied() == Some(UNREACHED) && open(n) {
                steps.set(n, next);
                queue.push_back(n);
            }
        }
    }
    steps
}
```

```rust
//! Cutting the longest detours through, so there is more than one way
//! round.

use std::collections::BTreeMap;

use rand::Rng;
use rl_core::{Direction, Grid, Grid2D, Point};
use rl_grid::TileId;

use crate::accrete::{Area, Join, Opening};
use crate::chain::{BuildError, Pass, Phase};
use crate::context::BuildContext;
use crate::walk::{UNREACHED, steps_from};

/// Opens a door in the wall between two areas that touch but are far
/// apart on foot, longest detour first.
///
/// Accretion alone builds a tree, one way to anywhere. A candidate is a
/// wall cell with the floor of two different areas on opposite sides and
/// solid wall on the other two, so a loop never widens an opening that is
/// already there. One candidate is drawn per pair of areas. The detour is
/// the walk between the two floor cells as the place stands, measured
/// again after each door, since one door shortens the others.
///
/// Longest first is what makes a loop worth having: a door that saves
/// three steps is a second door, and one that saves sixty is another way
/// round. It reads [`Area`]s and does nothing on a map with none.
#[derive(Debug, Clone, Copy)]
pub struct OpenLoops {
    /// The tile a loop opens as.
    pub door: TileId,
    /// The shortest detour, in orthogonal steps, worth cutting through.
    pub min_detour: u32,
    /// The most loops to open.
    pub max: u32,
}

impl<C: BuildContext> Pass<C> for OpenLoops {
    fn name(&self) -> &'static str {
        "open_loops"
    }
    fn phase(&self) -> Phase {
        Phase::Structures
    }
    fn apply(&self, ctx: &mut C) -> Result<(), BuildError> {
        let walkable = ctx.tiles().tables().walkable.clone();
        let bounds = ctx.terrain().bounds();
        let (w, h) = (bounds.width, bounds.height);
        let mut owner = Grid::<u32>::filled(w, h, 0);
        for a in ctx.outputs().iter::<Area>() {
            for c in &a.cells {
                owner.set(*c, a.index as u32 + 1);
            }
        }
        let joined: Vec<(usize, usize)> = ctx.outputs().iter::<Opening>().map(|o| (o.areas.0.min(o.areas.1), o.areas.0.max(o.areas.1))).collect();
        let taken: Vec<Point> = ctx.outputs().iter::<Opening>().flat_map(|o| o.cells.iter().copied()).collect();

        // Every wall cell between two areas not already joined, by pair. A
        // BTreeMap so the pairs are walked in one order on every run.
        let mut by_pair: BTreeMap<(usize, usize), Vec<(Point, Direction)>> = BTreeMap::new();
        for p in bounds.inflate(-1).cells() {
            let is_solid = |q: Point| ctx.terrain().get(q).is_some_and(|t| !walkable[t.index()]);
            if !is_solid(p) || taken.iter().any(|t| rl_core::geometry::manhattan(*t, p) <= 1) {
                continue;
            }
            for d in [Direction::East, Direction::South] {
                let (a, b) = (owner.get(p - d.offset()).copied().unwrap_or(0), owner.get(p + d.offset()).copied().unwrap_or(0));
                let walled = d.perpendicular().iter().all(|s| is_solid(p + s.offset()));
                if a != 0 && b != 0 && a != b && walled {
                    let (a, b) = (a as usize - 1, b as usize - 1);
                    if !joined.contains(&(a.min(b), a.max(b))) {
                        by_pair.entry((a, b)).or_default().push((p, d));
                    }
                }
            }
        }
        let mut candidates: Vec<((usize, usize), Point, Direction)> = Vec::new();
        for (pair, cells) in by_pair {
            let (p, d) = cells[ctx.rng().random_range(0..cells.len())];
            candidates.push((pair, p, d));
        }

        let mut opened: Vec<Point> = Vec::new();
        while (opened.len() as u32) < self.max {
            let open = |q: Point| ctx.terrain().get(q).is_some_and(|t| walkable[t.index()]);
            let mut best: Option<(u32, usize)> = None;
            for (i, (_, p, d)) in candidates.iter().enumerate() {
                if opened.iter().any(|o| rl_core::geometry::manhattan(*o, *p) <= 1) {
                    continue;
                }
                let steps = steps_from(w, h, open, [*p - d.offset()]);
                let detour = steps.get(*p + d.offset()).copied().unwrap_or(UNREACHED);
                if best.is_none_or(|(b, _)| detour > b) {
                    best = Some((detour, i));
                }
            }
            let Some((detour, i)) = best else { break };
            if detour < self.min_detour {
                break;
            }
            let (areas, p, facing) = candidates.remove(i);
            ctx.terrain_mut().set(p, self.door);
            ctx.emit(Opening { cells: vec![p], facing, areas, join: Join::Door });
            opened.push(p);
        }
        Ok(())
    }
}
```

```rust
//! Measuring a grown place, and holding it to what its recipe asked for.
//!
//! [`Survey`] decides nothing. It is in the engine because every game
//! that puts a thing somewhere for where that is would otherwise measure
//! the same facts again, differently. [`Require`] is what makes a loose
//! generator safe: a place that falls short fails, and the chain builds
//! another.

use rl_core::{Direction, Grid2D, Point};

use crate::accrete::{Area, Opening};
use crate::chain::{BuildError, Pass, Phase};
use crate::context::BuildContext;
use crate::dungeon::ExitPoint;
use crate::passes::StartPoint;
use crate::walk::{UNREACHED, steps_from};

/// What the survey found out about one area.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct AreaFacts {
    /// How many openings lead into it.
    pub openings: u32,
    /// One way in: somewhere a player went on purpose.
    pub dead_end: bool,
    /// Without it, some two other areas have no way between them.
    pub chokepoint: bool,
    /// Three ways or more lead out of it.
    pub junction: bool,
    /// Orthogonal steps from its nearest opening to the nearest cell of
    /// the shortest route from the start to the exit, or to the start
    /// where there is no exit. What is far from the direct way is what a
    /// player chose to go and find.
    pub seclusion: u32,
}

/// What the survey found out about a place.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Surveyed {
    /// One per [`Area`], at the area's index.
    pub areas: Vec<AreaFacts>,
    /// The independent loops among areas and openings: openings less
    /// areas plus one.
    pub loops: u32,
    /// The share of the map that can be walked on, in a hundred.
    pub open_pct: u32,
    /// Orthogonal steps from the start to the exit; `None` with no exit.
    pub route: Option<u32>,
}

/// Measures the place and emits one [`Surveyed`]. Runs once the start and
/// the exit are known; fails without a start, without an area, or when
/// the exit cannot be walked to.
#[derive(Debug, Clone, Copy, Default)]
pub struct Survey;

impl<C: BuildContext> Pass<C> for Survey {
    fn name(&self) -> &'static str {
        "survey"
    }
    fn phase(&self) -> Phase {
        Phase::Exits
    }
    fn apply(&self, ctx: &mut C) -> Result<(), BuildError> {
        let err = |reason: &str| BuildError::new("survey", reason);
        let start = ctx.outputs().first::<StartPoint>().ok_or_else(|| err("no start point emitted before it"))?.0;
        let exit = ctx.outputs().first::<ExitPoint>().map(|e| e.0);
        let areas: Vec<&Area> = ctx.outputs().iter::<Area>().collect();
        let openings: Vec<&Opening> = ctx.outputs().iter::<Opening>().collect();
        if areas.is_empty() {
            return Err(err("no area emitted before it"));
        }
        let walkable = ctx.tiles().tables().walkable.clone();
        let bounds = ctx.terrain().bounds();
        let (w, h) = (bounds.width, bounds.height);
        let open = |p: Point| ctx.terrain().get(p).is_some_and(|t| walkable[t.index()]);

        // The shortest route, walked down from the start to the exit.
        let mut route_cells = vec![start];
        let mut route = None;
        if let Some(exit) = exit {
            let to_exit = steps_from(w, h, open, [exit]);
            let at = |p: Point| to_exit.get(p).copied().unwrap_or(UNREACHED);
            if at(start) == UNREACHED {
                return Err(err("the exit cannot be walked to from the start"));
            }
            route = Some(at(start));
            let mut here = start;
            while here != exit {
                here = Direction::CARDINALS.iter().map(|d| here + d.offset()).find(|n| at(*n) != UNREACHED && at(*n) + 1 == at(here)).expect("a reached cell has a neighbour one step nearer");
                route_cells.push(here);
            }
        }
        let off_route = steps_from(w, h, open, route_cells);

        let neighbours = |i: usize| openings.iter().filter_map(move |o| if o.areas.0 == i { Some(o.areas.1) } else if o.areas.1 == i { Some(o.areas.0) } else { None });
        let facts = (0..areas.len())
            .map(|i| {
                let doors: Vec<Point> = openings.iter().filter(|o| o.areas.0 == i || o.areas.1 == i).flat_map(|o| o.cells.iter().copied()).collect();
                let count = openings.iter().filter(|o| o.areas.0 == i || o.areas.1 == i).count() as u32;
                let from: &[Point] = if doors.is_empty() { &areas[i].cells } else { &doors };
                let seclusion = from.iter().map(|p| off_route.get(*p).copied().unwrap_or(UNREACHED)).min().unwrap_or(UNREACHED);
                // Without area i, can every other still be reached from the first of them?
                let others: Vec<usize> = (0..areas.len()).filter(|j| *j != i).collect();
                let mut seen = vec![false; areas.len()];
                let mut stack: Vec<usize> = others.first().copied().into_iter().collect();
                if let Some(first) = others.first() {
                    seen[*first] = true;
                }
                while let Some(a) = stack.pop() {
                    for n in neighbours(a) {
                        if n != i && !seen[n] {
                            seen[n] = true;
                            stack.push(n);
                        }
                    }
                }
                let chokepoint = others.iter().any(|j| !seen[*j]);
                AreaFacts { openings: count, dead_end: count == 1, chokepoint, junction: count >= 3, seclusion }
            })
            .collect();

        let open_cells = bounds.cells().filter(|p| open(*p)).count() as u32;
        let surveyed = Surveyed { areas: facts, loops: (openings.len() as u32 + 1).saturating_sub(areas.len() as u32), open_pct: open_cells * 100 / (w * h) as u32, route };
        ctx.emit(surveyed);
        Ok(())
    }
}

/// Fails the build when the place falls short of what its recipe asked
/// for, naming the first bound it missed and both numbers.
#[derive(Debug, Clone)]
pub struct Require {
    /// The open share, at least and at most, in a hundred.
    pub open_pct: (u32, u32),
    /// The fewest areas drawn by each named shape.
    pub areas: Vec<(String, u32)>,
    /// The fewest loops.
    pub loops: u32,
    /// The largest share of areas, in a hundred, that may be dead ends.
    pub dead_end_pct: u32,
    /// The shortest walk from the start to the exit, in orthogonal steps.
    /// More than nought fails a place with no exit.
    pub route: u32,
}

impl<C: BuildContext> Pass<C> for Require {
    fn name(&self) -> &'static str {
        "require"
    }
    fn phase(&self) -> Phase {
        Phase::Finish
    }
    fn apply(&self, ctx: &mut C) -> Result<(), BuildError> {
        let fail = |reason: String| Err(BuildError::new("require", reason));
        let Some(s) = ctx.outputs().first::<Surveyed>() else {
            return fail("no survey emitted before it".to_string());
        };
        if s.open_pct < self.open_pct.0 || s.open_pct > self.open_pct.1 {
            return fail(format!("{}% of the map is open, outside {}% to {}%", s.open_pct, self.open_pct.0, self.open_pct.1));
        }
        for (shape, fewest) in &self.areas {
            let found = ctx.outputs().iter::<Area>().filter(|a| a.shape == *shape).count() as u32;
            if found < *fewest {
                return fail(format!("{found} areas drawn by {shape:?}, fewer than {fewest}"));
            }
        }
        if s.loops < self.loops {
            return fail(format!("{} loops, fewer than {}", s.loops, self.loops));
        }
        let dead = s.areas.iter().filter(|a| a.dead_end).count() as u32 * 100 / s.areas.len().max(1) as u32;
        if dead > self.dead_end_pct {
            return fail(format!("{dead}% of areas are a dead end, more than {}%", self.dead_end_pct));
        }
        match s.route {
            Some(route) if route < self.route => fail(format!("the exit is {route} steps from the start, nearer than {}", self.route)),
            None if self.route > 0 => fail(format!("there is no exit, and one was asked for {} steps away", self.route)),
            _ => Ok(()),
        }
    }
}
```

`load` parses with the same `Options` as `prefab::load`, then collects every problem into a `Vec<String>` and returns `ContentError::Invalid(errors)` if any, each line starting with the name of the shape, district or recipe it is about:

- two shapes, two districts or two recipes share a name;
- a district names an unknown shape, a recipe an unknown district, a requirement an unknown shape;
- a weight list with no weight above nought (the message contains the word `weight`);
- a range whose fewest exceeds its most, or whose fewest is below 1;
- a `Cross` whose `short` most is not less than its `long` fewest;
- `Mouth(0)` (the message contains `Mouth`);
- `open_pct` outside 1 to 100, `bend_pct` or `dead_end_pct` above 100, `patience` of nought, a `require.open_pct` whose first exceeds its second (each message contains the field's name);
- a required shape that no district of the recipe carries with a weight above nought;
- a recipe whose size, less the border, is smaller than the fewest of the smallest shape any of its districts can draw (width against width, height against height).

Name resolution turns each `(String, u32)` row into `(usize, u32)`.
`LayoutDef::recipe` is a linear search by name.

```rust
//! A layout file as the passes that grow it.
//!
//! `rl-rules` owns the file and names no mapgen type; `rl-mapgen` owns
//! the passes and reads no file. This is the one place that sees both, as
//! [`Prefabs::piece`](crate::prefabs::Prefabs::piece) is for a prefab.

use rl_grid::TileId;
use rl_mapgen::accrete::{Accrete, Cross, District, Join, Passage, Rectangle, Shape};
use rl_mapgen::{BuildError, OpenLoops, Require};
use rl_rules::layout::{JoinDef, LayoutDef, ShapeKind};

/// The passes one recipe asks for, and the size of the map to run them on.
///
/// A game puts them in its own chain: `accrete` and `loops` first, its
/// stamps, its start and exit, a `Survey`, and `require` last.
pub struct LayoutPasses {
    /// The map's width and height.
    pub size: (i32, i32),
    /// Growth.
    pub accrete: Accrete,
    /// The loops cut after it.
    pub loops: OpenLoops,
    /// What the built place must meet.
    pub require: Require,
}

/// The passes for the recipe called `recipe`, carving `floor` and opening
/// doors as `door`. An error naming the recipe when there is none, so a
/// chain can `?` it.
pub fn passes(def: &LayoutDef, recipe: &str, floor: TileId, door: TileId) -> Result<LayoutPasses, BuildError> {
    let r = def.recipe(recipe).ok_or_else(|| BuildError::new("layout", format!("no recipe is called {recipe:?}")))?;
    let join = |j: JoinDef| match j {
        JoinDef::Door => Join::Door,
        JoinDef::Arch => Join::Arch,
        JoinDef::Mouth(n) => Join::Mouth(n),
    };
    let shapes: Vec<Box<dyn Shape>> = def
        .shapes
        .iter()
        .map(|s| -> Box<dyn Shape> {
            let (name, join) = (s.name.clone(), join(s.join));
            match s.kind {
                ShapeKind::Rectangle { w, h } => Box::new(Rectangle { name, w, h, join }),
                ShapeKind::Cross { long, short } => Box::new(Cross { name, long, short, join }),
                ShapeKind::Passage { width, length, bend_pct } => Box::new(Passage { name, width, length, bend_pct, join }),
            }
        })
        .collect();
    let districts = def.districts.iter().map(|d| District { name: d.name.clone(), shapes: d.shapes.clone() }).collect();
    Ok(LayoutPasses {
        size: r.size,
        accrete: Accrete { floor, door, shapes, districts, mix: r.districts.clone(), districts_per_10k: r.districts_per_10k, open_pct: r.open_pct, patience: r.patience },
        loops: OpenLoops { door, min_detour: r.loops.min_detour, max: r.loops.max },
        require: Require {
            open_pct: r.require.open_pct,
            areas: r.require.areas.iter().map(|(i, n)| (def.shapes[*i].name.clone(), *n)).collect(),
            loops: r.require.loops,
            dead_end_pct: r.require.dead_end_pct,
            route: r.require.route,
        },
    })
}
```

```rust
    fn generate(&self, map: MapId) -> Result<BaseContext, BuildError> {
        let deck = deck_of(map);
        // One stream per deck, so building deck 2 first does not change deck 1.
        let seed = RunSeed(self.seed.0 ^ (deck as u64) << 32);
        let grown = rl_engine::rl_bevy::layout::passes(&self.layout, recipe_of(deck), self.deck, self.hatch)?;
        let (width, height) = grown.size;
        let mut chain = Chain::new()
            .then(grown.accrete)
            .then(grown.loops)
            .then(StampOneOf { name: "armory", choices: self.armories()?, at: Placement::AnyRoom, orient: Orient::TurnedOrMirrored })
            .then(StampOneOf { name: "store", choices: self.stores()?, at: Placement::AnyRoom, orient: Orient::TurnedOrMirrored });
        // ... the guard post and reactor/core blocks exactly as they are ...
        let start = RandomStart.clear_of_stamps(crate::droids::MIN_DISTANCE_FROM_ENTRY);
        let rooms = StampEachRoom { name: "furnish", choices: self.rooms()?, orient: Orient::TurnedOrMirrored };
        chain
            .then(start)
            .then(FarthestExit)
            .then(Survey)
            .then(rooms)
            .then(grown.require)
```

- Add `render`:

```rust
    /// The deck as rows of glyphs, for `foundry --deck` and for reading a
    /// layout before calling a recipe done: `#` what cannot be walked on,
    /// `.` what can, `+` a hatch, `<` the way in and `>` the way down.
    pub fn render(&self, map: MapId) -> Result<String, BuildError> {
        let built = self.build(map, None)?;
        let tables = self.tiles.tables();
        let bounds = built.terrain.bounds();
        let mut out = String::new();
        for y in 0..bounds.height {
            for x in 0..bounds.width {
                let p = rl_engine::rl_core::Point::new(x, y);
                let tile = built.terrain.get(p).expect("in bounds");
                out.push(if p == built.entry {
                    '<'
                } else if Some(p) == built.exit {
                    '>'
                } else if tile == self.hatch {
                    '+'
                } else if tables.walkable[tile.index()] {
                    '.'
                } else {
                    '#'
                });
            }
            out.push('\n');
        }
        Ok(out)
    }
```

# atglyph-rules

Content registries, stats, damage, statuses, factions, equipment, monster AI and quests, as shapes a game fills (tier 1 of the atglyph engine).
It needs no Bevy, so it can be used on its own in any Rust project.
[`atglyph`](https://github.com/rudehn/rl-engine) is the whole engine, and a game depends on `atglyph` and reaches it as `atglyph::rules`.
